# Contributing to AI Prompt Library

Thanks for wanting to make this library better! 🎉

## Ways to contribute

### 1. Add / improve prompts
The prompt data lives in `index.html` as an inline JSON array (look for the prompts
data section near the bottom of the file). To add or edit a prompt:

1. Fork the repo
2. Edit the JSON array — each entry has a title (EN), a `zh` title, a category, and the
   prompt text
3. Add the category to the category list if it's new
4. Test locally: open `index.html` in your browser and verify search/filter/copy work
5. Submit a PR with a clear description of what you added and why it's useful

### 2. Report issues
Found a broken prompt, a category that's missing, or something that doesn't render?
Open an issue — include your browser and OS.

### 3. Spread the word
Star the repo, share the [live demo](https://slashmantools.us/ai-prompt-library/), or
link it from your own resources.

## Guidelines
- Keep prompts **practical and battle-tested** — quality over quantity
- Keep entries concise; avoid duplicates (check search first)
- Preserve the bilingual (EN/zh) structure
- No spam, no affiliate links inside prompt text
